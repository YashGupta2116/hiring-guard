## Do not redo
- Don't decay only the incoming observation's channel in `Engine._process_one` -- every channel must decay to the current observation's `t_ms` on every step, or idle channels' LLR goes stale and the leave-one-out `score_delta` reconstruction stops matching. See the fix noted above.
- Don't compare a `deque` to a `list` with `==` in tests (`deque([]) == []` is `False`, not `True`); use `len(...) == 0` or cast with `list(...)`.
- Don't gate only flag *emission* on `calibrating` in `Engine._process_one` and assume that's what "observe-only" means -- evidence accumulation (`state.add()`) has to be gated too, or the calibration window quietly charges the candidate for noise it promised not to score. Corroboration eligibility and decay-origin both fall out for free once `state.add()` itself is gated; don't special-case them separately.
- Don't pass `lw=0`/`linewidth=0` to a hatched `axvspan`/`axhspan`/patch without also setting `edgecolor` explicitly. `hatch.color` defaults to the rcParam value `"edge"`, so no edgecolor means no visible hatch stroke at all -- it silently renders as a flat fill instead of erroring. Reproduce in isolation before trusting a hatch call looks right; a screenshot glance can miss it, especially at small figure sizes.
- Don't assume `_build_timeline()`'s `session_end` (derived from the last observation's `t_ms`) covers a fixture whose driver actions run past its last observation -- it doesn't, and the figure silently clips instead of erroring. Pass `session_end_ms` explicitly for any fixture like the demo's, where dismissal/suppress/resume are driver actions with no corresponding observation. Render the actual PNG and look at it; nothing asserts the x-axis span in a test.
- Don't try to make a corroborated flag land in a specific score band by adjusting its duration/confidence without first checking whether the channel weight and severity cuts make that band reachable at all. A medium-severity flag on a channel weighted >= 1.15 needs a boosted LLR >= 1.5, which alone can already cross a band boundary before any other channel's evidence is added -- solve the inequality by hand before iterating on numbers.
- Don't call `Engine.suppress()`/`resume()` expecting the window's timestamp to be whatever session-time the caller "meant" -- both read `Engine._t_now`, which only moves via `ingest()`. With no observation at the intended timestamp, the window silently opens/closes at the last ingested observation's time instead, with no error. Set `engine._t_now` directly first if nothing is being ingested at that moment.
